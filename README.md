## Description

Lunk YT Summy is a small desktop tool for generating summaries of YouTube videos using Google Gemini. 
It is designed for people who want to understand the main points of a video without watching the full thing, the internet is big, too much clickbait and content creators reapting themselves over and over
The app does not just scrape text from the page or rely on metadata alone: it analyzes the video itself and uses Gemini to extract the important arguments, key facts, and conclusions.

The goal is simple: paste a link, provide your Gemini API key, and receive a structured summary of the video content without the clickbait and fluff.

## Features

- Paste a YouTube link directly into the GUI
- Sends the actual video to Google Gemini for analysis
- Extracts the most important facts, arguments, and conclusions from the video
- Generates a structured markdown-style summary in the app
- Lets you copy the generated summary to the clipboard
- Saves the API key locally in a configuration file
- Works as a lightweight desktop application built with Tkinter

## Requirements

- Python 3.9+
- A valid Google Gemini API key
- Internet access :-)

Important: This tool does not work without a Gemini API key. The summary is generated by analyzing the video through Gemini, so a valid key is required to send the request and receive the summary. A *free* key should suffice for some video summarizes.

## Instructions

At first, you need a Gemini API key.
You can generate one in the Google AI Studio / Gemini area and paste it into the application when prompted.
The key is stored locally in a file called ```key.ini```, so you normally only need to enter it once.

1. Clone or download this project

2. Open a terminal in the project folder

3. Install the required Python dependencies

   ```bash
   pip install google-genai
   ```

4. Start the application

   ```bash
   python app.py
   ```

5. Paste a YouTube URL into the input field and click the summarize button

6. Wait a moment while the app analyzes the video and generates the summary

7. Copy the result to the clipboard if you want to save it elsewhere

## How it works

The app does the following:

- removes unnecessary tracking parameters and keeps a clean video URL
- sends the actual video to Gemini for analysis
- extracts the main arguments, facts, and conclusions from the video content
- generates a structured summary and displays it in the GUI window

This is not a simple metadata summary. It analyzes the actual video content through Gemini, which is why a valid Gemini API key is required.

## Supported video links

The app is intended for normal YouTube links, including:

- standard watch URLs
- short links
- embed/shorts/live URLs
- summary is in the same language as the source video

Example:

```text
https://www.youtube.com/watch?v=H9PVWUvlOBY
```

## Notes / Troubleshooting

- If there is no API key saved yet, the app will ask you to enter one.
- The app needs a valid Gemini API key before it can analyze the video and generate a summary.
- If the URL is invalid, the app will show a warning and nothing will be sent.
- If a video is very long, the initial analysis can take a bit more time.
- The app is intended for quick summaries of video content, not for full transcript extraction or advanced editing workflows.

## Disclaimer

**Use this tool at your own risk.**
The app depends on external services and your API key. Make sure you understand the usage limits, billing, and such things when using Google Gemini.
